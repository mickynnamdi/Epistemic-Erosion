# data/

No data is distributed with this repository. The scripts write the samples here (git-ignored):
see [../docs/DATA.md](../docs/DATA.md) for how to obtain and rebuild every input.

The only tracked files are `hosted_samples/seed{0,1,2}.json`: the public document ids
(Multi-LexSum case ids, SciTLDR paper ids, PubMed ids) of the hosted-model study (Table 2).
